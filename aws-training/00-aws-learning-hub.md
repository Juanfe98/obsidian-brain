## Learning Paths

### 🎯 Quick Start (Linear Path)
Perfect if you're new to AWS and want a structured approach:

1. [[cloud-computing-basics|Cloud Computing Basics]] → [[aws-infrastructure|AWS Infrastructure]]
2. [[networking-overview|Networking Overview]] (understand VPC first - it's foundational)
3. [[ec2|EC2]] (launch virtual servers)
4. [[s3|S3]] (understand storage)
5. [[databases-overview|Databases Overview]] (data persistence)

### 🎓 By Use Case

**Building Web Applications:**
[[networking-overview|VPC]] → [[ec2|EC2]] → [[databases-overview|RDS]] → [[s3|S3]]

**Data & Analytics:**
[[s3|S3]] → [[ec2|EC2]] → [[databases-overview|DynamoDB]]

**Infrastructure Foundation:**
[[cloud-computing-basics|Cloud Computing Basics]] → [[aws-infrastructure|AWS Infrastructure]] → [[networking-overview|Networking Overview]]

Follow this study path:

1. **Learn** → Complete all Fundamentals and Core Services notes
2. **Compare** → Review all comparison documents in `03-comparisons/`
3. **Reference** → Study the [[04-study-aids/quick-reference-guide|Quick Reference Guide]]
