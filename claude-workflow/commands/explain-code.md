# Explain Code

Explain the requested code or flow without editing files.

## Workflow

1. Inspect the relevant files.
2. Trace the flow from entry point to output.
3. Explain the responsibilities of each relevant module.
4. Identify important state, data flow, side effects, and dependencies.
5. Mention risks, confusing areas, or hidden coupling.
6. Do not edit files.

## Output

1. High-level summary
2. Important files
3. Step-by-step flow
4. Key dependencies
5. Risks or confusing parts
