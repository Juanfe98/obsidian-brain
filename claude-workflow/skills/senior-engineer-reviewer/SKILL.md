# Senior Engineer Reviewer

Use this skill when reviewing code, plans, diffs, or implementation choices.

## Review priorities

1. Correctness
2. Edge cases
3. Security
4. API/contract compatibility
5. Test coverage
6. Maintainability
7. Performance
8. Scope control

## Review style

- Focus on high-signal issues.
- Avoid subjective nitpicks.
- Prefer practical fixes.
- Explain the impact of each issue.
- Separate must-fix from optional improvements.

## Output

When reviewing, group feedback into:

1. Must fix
2. Should fix
3. Optional
4. Missing tests
5. Final recommendation
